# mcgm-tool

Утилита для переноса участков миров Minecraft Java Edition (`1.18 – 26.x+`) в карты Garry's Mod (`.bsp`) с текстурами, освещением, табличками, дверями, кнопками, водой и аддоном физики передвижения. Работает на Windows 10+.

## Зависимости

- **Garry's Mod** (Steam) — используется `studiomdl.exe`, компиляторы карт и папка `garrysmod/`. Находятся автоматически.
- **VTFLib (`VTFCmd.exe`)** — [сайт](https://nemstools.github.io/pages/VTFLib-Download.html) / [GitHub](https://github.com/NeilJed/VTFLib). Распаковать в `C:\Tools\VTFLib\` или в `tools\VTFLib\` рядом с `mcgm.exe`.
- **Minecraft: Java Edition** — установленный клиент нужной версии (поддерживаются стандартный лаунчер, Prism Launcher и MultiMC).
- **Tools++ (`vbsp++`, `vvis++`, `vrad++`)** — [GitHub Releases](https://github.com/ficool2/misc_tools/releases), опционально. Ускоряет компиляцию и добавляет GPU-расчёт света. Распаковать в `C:\Tools\Tools++\` или в `Tools++\` рядом с `mcgm.exe`.

`mcgm.exe` собирается как GUI-приложение без консольного окна, поэтому при запуске CLI-команд в PowerShell добавляйте `| Out-Host`, чтобы видеть вывод:

```powershell
.\mcgm.exe --check-env | Out-Host
.\mcgm.exe --list-instances | Out-Host
.\mcgm.exe --detect-tools | Out-Host
```

## Использование (GUI)

1. Запустите `mcgm.exe`.
2. Выберите инстанс лаунчера (или добавьте папку через **+ Папка...**) и мир из списка. Кнопка **Обзор...** открывает папку `saves/` выбранного инстанса.
3. Укажите область вокруг спавна (`±32`, `±64`, `±128`) или задайте координаты вручную.
4. Проверьте имя карты, пресет качества и освещение, нажмите **Создать карту**.
5. После сборки нажмите **Открыть GMod** или загрузите карту командой `map <имя_карты>` в консоли игры.

Дополнительные параметры (измерение, масштаб, папка вывода, сохранение `.vmf`, журнал сборки) открываются кнопками **Дополнительно** и **Журнал**.

## Аддон физики

При экспорте в GMod устанавливается Lua-аддон с физикой из Minecraft (подъём на 1 блок, автопрыжок, спринт, лестницы/лианы, лёд, блоки слизи и мёда, вода и лава).

- Включить или отключить во время игры: `!mcphysics` в чат или `mcgm_toggle_physics` в консоль.
- Настройки находятся в `Q-меню -> MCGM`.

## Паркур-метки на табличках

На табличках в Minecraft можно расставить игровые метки для паркур-карт — они распознаются по **первой строке лицевой стороны** (регистр и пробелы по краям не важны) и работают в Garry's Mod независимо от настроек Minecraft-физики (`--no-mc-physics` не отключает метки):

- **Чекпоинт** (2-я строка — необязательное название):
  ```text
  [mcgm checkpoint]
  Башня
  ```
- **Финиш** (2-я строка — необязательное название):
  ```text
  [mcgm finish]
  Вершина
  ```

Как работает возрождение в Sandbox:
- До первого чекпоинта игрок появляется на обычном спавне карты.
- При входе в зону чекпоинта (перед лицевой стороной настенной таблички или рядом со стоящей табличкой) выбирается безопасная точка с опорой под ногами и свободным пространством для игрока; прогресс сохраняется отдельно для каждого игрока, а при смерти и последующем возрождении игрок возвращается на последний чекпоинт. Если безопасного места рядом нет, сохраняется предыдущий чекпоинт и в консоль сервера выводится предупреждение с координатами метки.
- Вход в зону `[mcgm finish]` один раз выводит сообщение о прохождении и очищает чекпоинт этого игрока — следующее возрождение происходит на обычном спавне и начинает новый забег. Состояние всех игроков сбрасывается при смене карты.

## Мод для выделения (Fabric 1.20.1, опционально)

Необязательный клиентский мод для выбора координат прямо в игре.

Установка:
1. Установите Minecraft `1.20.1` с Fabric Loader (`>=0.14.21`), Fabric API и Java 17+.
2. Скачайте `mcgm-bridge-1.0.0.jar` из [Releases](https://github.com/AndreyAbr/mcgm-tool/releases) (или соберите через `minecraft_mod\build.ps1`).
3. Скопируйте файл в папку `mods/` вашего клиента (`%APPDATA%\.minecraft\mods\` или в `mods/` нужного инстанса Prism Launcher / MultiMC).
4. После запуска нажмите `M` и при необходимости укажите путь к `mcgm.exe`.

Управление:
- `[` — первая точка (`Pos 1`)
- `]` — вторая точка (`Pos 2`)
- `M` — меню настроек
- `/mcgm export` — открыть меню экспорта выделенной области
- `/mcgm gui` — открыть окно MCGM

## CLI

Примеры запуска из командной строки:

```powershell
.\mcgm.exe --world "C:\Users\<User>\AppData\Roaming\.minecraft\saves\World" `
  --coords 100 64 100 228 140 228 `
  --name my_build `
  --category mcgm `
  --map gm_minecraft_build `
  --import-to-gmod | Out-Host

.\mcgm.exe --instance "26.2" `
  --coords -275 61 29 -215 111 89 `
  --preset preview | Out-Host
```

Основные флаги:

- `--lighting-style <minecraft|gmod|bright|night>` — пресет освещения и неба.
- `--preset <preview|balanced|hq>` — пресет качества сборки.
- `--fast-vrad` / `--hq-light` — быстрый расчёт света или повышенное качество (полный VVIS).
- `--collision-mode <per_chunk_phy|vmf_brushes>` — коллизии моделями или VMF-брашами (`--vmf-brushes`).
- `--chunk-size <N>` — размер чанка при экспорте (по умолчанию `64`).
- `--max-workers <N>` — число потоков для компиляции моделей.
- `--reuse-cache` — использовать кэш уже скомпилированных моделей.
- `--export-vmf` — сохранить исходный `.vmf`.
- `--no-mc-physics` — не устанавливать аддон физики.
- `--no-import-to-gmod` — не копировать файлы в `garrysmod/`.
- `--gui` — принудительно открыть окно программы; `--auto-start` — сразу начать экспорт.
- `--list-instances` — список найденных инстансов и папок `saves` (поддерживает `--json`).
- `--instance <имя>` — выбрать инстанс для разрешения `--world` или автовыбора последнего мира.
- `--detect-tools` — найти внешние утилиты и обновить `config.json`; `--check-env` — проверка окружения.

## Сборка из исходников

Требуется [Rust](https://rustup.rs/), а для сборки мода — [JDK 17+](https://adoptium.net/).

```powershell
cargo test
cargo build --release

# Мод Fabric 1.20.1
powershell -ExecutionPolicy Bypass -File minecraft_mod\build.ps1
```

## Конфигурация (config.json)

Файл создаётся и обновляется командой `--detect-tools`:

- `studiomdl_path` — путь к `studiomdl.exe`
- `vbsp_path`, `vvis_path`, `vrad_path` — пути к компиляторам карт
- `vtfcmd_path` — путь к `VTFCmd.exe`
- `game_dir` — путь к папке `garrysmod/`
- `hammer_path` — путь к `hammer.exe` (опционально)
- `vanilla_jar_path` — путь к клиентскому `.jar` Minecraft
- `world_path` — путь к `saves/` или папке мира
- `instance_dirs` — дополнительные пути к папкам лаунчеров, `instances/` или `saves/` (опционально)
- `scale_factor` — единиц Source на 1 блок Minecraft (по умолчанию `39.37`)
- `max_convex_pieces` — максимум выпуклых частей коллизии на модель (по умолчанию `64`)
